# LeetCode-250-Roadmap
# LeetCode Solutions

My solutions to the [NeetCode 250](https://neetcode.io/roadmap) roadmap, worked through topic by topic. Accepted submissions are pushed here automatically by the LeetHub extension.

## Structure

Each problem gets its own folder, named by problem number and slug:

```
0001-two-sum/
  README.md      # problem statement and link (auto-generated)
  two-sum.py     # my accepted solution
```

Folders are flat. The topic organisation lives in the roadmap below, not in the directory tree.

## Approach

- Work through the roadmap in order, one topic at a time, easy problems before mediums.
- Attempt each problem on my own first, then compare against the reference solution.
- Name the pattern behind each problem (e.g. two pointers, sliding window, BFS/DFS) so I'm learning the pattern rather than memorising the answer.
- Each day: revise a few old easy problems, solve at least one medium, then move on to new material.
